# Leonardo Rivaldo

**Senior Software Engineer** · Fundão, Portugal

## Bio

I am a software engineer with a background spanning IT support, full-stack web development and enterprise front-end engineering.

I began my career working with computer maintenance, network support, user services and IT administration. I then moved into web development with HTML, CSS, JavaScript/jQuery and PHP, before specializing in AngularJS and Angular and expanding into React, Node.js, TypeScript, Sass and MongoDB.

My experience includes telecommunications, public-sector, automotive and medical projects. Along the way, I have taken on responsibilities in front-end development, UI/UX, software architecture, system integration and team leadership.

More recently, I have worked with distributed systems, CI/CD pipelines, Linux environments, hardware-integrated platforms and cloud-based architectures. At Capgemini, I am assigned to Siemens to help build a foundation UI library and to lead, plan and develop a human-in-the-loop application for AI agent workflows.
